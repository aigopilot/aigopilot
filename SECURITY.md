# Security

If you find a security problem in AigoPilot, the studio, an agent or aigopilot.com, please do not open a public issue.

Write to **info@aigopilot.com** with "Security" in the subject, or use [aigopilot.com/support](https://aigopilot.com/support). Tell us what you found, the build or page it affects, and how to reproduce it. We answer as soon as we can and tell you when it is fixed.

Please give us a reasonable time to fix it before you speak about it in public, and do not access other people's data while testing.

Only the newest build on aigopilot.com receives fixes. Installed studios and agents update themselves to it within a day.
