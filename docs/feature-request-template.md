# Feature request template

Copy this template into a [new issue](https://github.com/aigopilot/aigopilot/issues/new). Public issues are for non-sensitive reports only.

## What are you trying to do?

Describe the task or workflow.

## What is difficult now?

Explain the problem and any workaround you use.

## What would help?

Describe the result you want. A concrete example is useful.

## Availability check

Check https://aigopilot.com/features for existing, in-development and planned features, and search existing issues before posting.

Keep private project and account information out of this public issue.
