# AigoPilot product release notes

This file records confirmed product releases separately from changes to this documentation repository. Development work is recorded under **Unreleased** until a public release is confirmed.

## Status confirmed — 13 October 2026

The product owner confirmed the following status on this date. This is a status record, not a claim that the agents were first released on this date.

### Released components

- **AigoPilot remote agent for Windows.**
- **AigoPilot remote agent for macOS.**

These are remote-computer components, not releases of the main AigoPilot application. Download information and setup guidance are on the [official remote computers page](https://aigopilot.com/features/remote-computers). Agent version numbers and original release dates have not been recorded here.

### Unreleased — main desktop studio

**The main AigoPilot application has not been publicly released.** The current documentation captures a development preview for Windows 10 and Windows 11:

- A shared desktop workspace for Claude Code, Codex and Grok using their official command-line tools and the user's own accounts.
- Project and session overview, prompts, replies, questions and permission requests.
- Discovery of existing Claude Code and Codex sessions.
- Notifications when work finishes or needs attention.
- Conversation search and inspection of files changed during a session.
- Linked-session handover for long Claude Code and Codex conversations.
- Remote-computer workflows using Windows and macOS agents.
- Public setup guides and light/dark studio previews using fictional sample data.

This is a baseline of the workflows documented so far, not a versioned list of newly shipped features or a complete product specification. No public studio version, release date or download availability is asserted.

### Other unreleased work

- The iPhone companion is in testing and is not publicly released.
- A Linux agent and full Mac and Linux studio editions are planned, without a promised release date.
- Optional plugin information is described in the [Marketplace](https://aigopilot.com/marketplace); listings do not establish a public studio release.
